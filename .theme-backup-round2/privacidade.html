Política de Privacidade

Versão 1.0 — Vigente a partir de junho de 2025

Esta Política de Privacidade descreve como o Sistema Serve coleta, utiliza, armazena e protege seus dados pessoais, em conformidade com a Lei Geral de Proteção de Dados Pessoais (LGPD — Lei nº 13.709/2018).

1. Responsável pelo Tratamento

O controlador dos dados é a organização responsável pelo Sistema Serve. Para dúvidas ou exercício de direitos, entre em contato com o administrador do sistema.

2. Dados Coletados

Coletamos apenas os dados necessários para o funcionamento do sistema:

  • Nome completo — identificação nas escalas e na interface.
  • E-mail — credencial de acesso único.
  • Senha — armazenada de forma irreversível (hash BCrypt).
  • Foto de perfil (opcional) — armazenada localmente no servidor.
  • Dados do voluntário (opcionais): telefone, gênero, data de nascimento — usados apenas para gestão interna de escalas.
  • Registros de auditoria — ações realizadas no sistema (endereço IP, data/hora, operação).

3. Finalidade do Tratamento

Seus dados são utilizados exclusivamente para:

  • Autenticação e controle de acesso ao sistema.
  • Gestão de escalas, voluntários e ministérios da organização.
  • Rastreabilidade e segurança das operações (auditoria interna).
Sem dados enviados a terceiros. Nenhum dado pessoal é compartilhado com serviços externos. O sistema não utiliza serviços de terceiros para geração de avatares ou qualquer outro processamento de dados pessoais.

4. Base Legal (LGPD Art. 7)

O tratamento de dados é realizado com base no consentimento do titular (Art. 7, I) e na execução de contrato ou procedimentos preliminares (Art. 7, V), necessários para o uso do sistema.

5. Armazenamento e Segurança

Os dados são armazenados em banco de dados local da organização. Adotamos medidas de segurança técnicas e organizacionais para proteção contra acesso não autorizado, incluindo:

  • Senhas com hash BCrypt (irreversível).
  • Autenticação via tokens JWT com expiração definida.
  • Controle de acesso por papel (administrador / voluntário).

6. Retenção dos Dados

Os dados são mantidos enquanto a conta estiver ativa. Após exclusão da conta, os dados pessoais identificáveis são removidos ou anonimizados. Registros históricos de escalas são mantidos de forma anonimizada para integridade dos relatórios.

7. Seus Direitos (LGPD Art. 18)

Como titular dos dados, você tem direito a:

  • Confirmação e acesso aos seus dados (via tela "Meu Perfil").
  • Correção de dados incompletos ou desatualizados.
  • Eliminação dos dados pessoais (exclusão de conta).
  • Revogação do consentimento a qualquer momento.
  • Informação sobre o compartilhamento de dados (não aplicável — não compartilhamos).

Para exercer esses direitos, utilize as funcionalidades da tela "Meu Perfil" ou entre em contato com o administrador do sistema.

8. Encarregado pelo Tratamento de Dados (DPO)

Nos termos do Art. 41 da LGPD, a organização responsável por esta instância do Sistema Serve deverá designar um Encarregado pelo Tratamento de Dados (DPO — Data Protection Officer) e tornar público o seu contato.

Contato do Encarregado:
O contato do encarregado desta instância deve ser informado pelo administrador da organização. Para solicitar informações, exercer direitos ou registrar reclamações, entre em contato com o administrador do sistema.

9. Resposta a Incidentes de Segurança (Art. 48)

Em caso de incidente de segurança que possa acarretar risco ou dano relevante aos titulares (ex.: acesso não autorizado a dados pessoais), a organização se compromete a:

  • Notificar a Autoridade Nacional de Proteção de Dados (ANPD) em prazo razoável após a ciência do incidente.
  • Comunicar os titulares afetados quando o incidente puder lhes causar risco ou dano significativo.
  • Registrar e investigar o incidente, adotando medidas corretivas e preventivas.

10. Tratamento de Dados de Menores de Idade (Art. 14)

Se a organização contar com voluntários menores de 18 anos, o tratamento de seus dados pessoais requer o consentimento específico de ao menos um dos pais ou responsável legal, conforme o Art. 14 da LGPD.

O sistema exibirá um aviso ao cadastrar um voluntário com data de nascimento que indique menoridade. A organização é responsável por obter e registrar o consentimento do responsável legal antes de incluir dados de menores no sistema.

11. Alterações nesta Política

Esta política pode ser atualizada periodicamente. A versão vigente é sempre indicada no cabeçalho. Alterações significativas serão comunicadas no sistema.
